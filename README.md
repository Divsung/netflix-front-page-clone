Netflix Front Page Clone

A front-page clone of Netflix built using HTML and CSS. This project recreates the layout, visual design, navigation, hero section, and content sections of the Netflix homepage for practice and learning purposes.

Technologies Used

- HTML
- CSS

Features

- Netflix-inspired homepage layout
- Navigation bar
- Hero/banner section
- Movie and show sections
- Responsive design elements
- Custom styling using CSS

Purpose

This project was created to practice HTML and CSS and improve my understanding of website layouts and UI design.
